# Changelog

## 0.1.0 - 2026-05-27

First standalone release candidate.

- Adds bilingual one-pass deployment menu for existing Fractald nodes.
- Deploys official `fractal-indexer` and `stake-indexer` Docker images.
- Supports optional `proof-publisher` dry-run configuration.
- Adds persistent `tmux`/`screen` launcher to survive SSH disconnects.
- Adds GitHub issue templates, PR template, validation workflow, and publishing docs.
- Explicitly excludes Fractald node installation and custom commission logic.
